# Stage B input routing and raw-count contract

Stage A format labels are candidates. Stage B verifies the physical input, groups manifest rows by the complete `input_signature`, reads each signature once, and requires every expression reader to return the same contract: `counts`, `reader`, `input_signature`, `source_path`, `input_cells`, `input_features`, and (when useful) `original_cell_ids`. `counts` is validated by `assert_counts()` and converted to a genes × cells `dgCMatrix` before cell/sample mapping.

| Format | Detection | Reader | Raw-count rule | Sample mapping | Performance rule | Failure conditions |
|---|---|---|---|---|---|---|
| 10x MTX trio | Manifest `10x_mtx`; exactly one matrix, feature/genes and barcode member, plain or gzipped | `Seurat::Read10X()` after temporary canonical gzip normalization | `count_source=counts`; integer, finite, nonnegative | One-sample barcodes are prefixed with sample; shared trios require an exhaustive cell map | One physical trio is read once; no per-sample Seurat object | Missing/ambiguous member, mixed biological feature types without Gene Expression, invalid counts |
| 10x H5 | Manifest candidate plus real `matrix/data`, `matrix/barcodes`, `matrix/features` schema | `Seurat::Read10X_h5()` | `count_source=counts`; schema and counts are both checked | Prefix one sample or use exhaustive cell map | One H5 read per signature | H5AD extension, ordinary H5 without 10x schema, invalid counts |
| H5AD / H5AD.gz | Manifest `h5ad`; extension must remain H5AD | Prefer `zellkonverter::readH5AD(reader="R")`; explicit `GEO_SINGLE_CELL_PYTHON` anndata fallback only when native packages are unavailable | Exact `count_source`: `X`, an assay/layer name, or `raw:<assay>`; selected matrix must pass raw integer validation | Verified cell map for multi-sample input; author obs is not imported automatically | One selected matrix is exported/read once; gzip uses one temporary decompression | Missing source, normalized/noninteger values, reader warning, unavailable native packages without explicit Python |

## Signature, mapping and construction rules

The expression signature includes at least `local_path`, `file_type`, `count_source`, `delimiter`, `orientation`, `feature_column`, `drop_columns`, `assay`, and `layer`. Rows sharing one path but disagreeing on any reader field stop with `Shared input has inconsistent reader configuration across manifest rows.` A build-local `loaded_inputs` cache makes the one-read rule observable and testable.

The metadata mapper creates the complete named `cell_sample_map` separately from expression reading. For pooled inputs, mapping requires nonblank unique cell IDs, nonblank samples, exact equality with matrix cells, and exact equality with the manifest samples assigned to that input. It does not inner-join or silently discard cells.

Prepared sparse matrices must have identical feature sets. Identical sets in a different order are reordered to the reference; real differences stop with `Feature sets differ between samples; explicit reconciliation is required.` No intersection, union, zero filling or gene deletion is allowed.

All aligned counts are combined before exactly one `CreateSeuratObject(counts=..., min.cells=3, min.features=200, project=gse)` call. Final retained cells are reindexed through `cell_sample_map`, then manifest metadata is attached. The serialized standard object contains one RNA counts layer and no author PCA, UMAP, normalized data, SCT/integrated assays, graphs, neighbors, clusters, or other analysis state.

Dependencies are route-scoped: base uses Seurat, SeuratObject, Matrix and jsonlite; text adds data.table; 10x H5 adds hdf5r; native H5AD adds zellkonverter, SingleCellExperiment and SummarizedExperiment. Missing optional packages block only their route and are never installed automatically.

Primary documentation: [Seurat Read10X](https://satijalab.org/seurat/reference/read10x), [Read10X_h5](https://satijalab.org/seurat/reference/read10x_h5), [Seurat v5 layers](https://satijalab.org/seurat/articles/seurat5_essential_commands), [zellkonverter readH5AD](https://theislab.github.io/zellkonverter/reference/readH5AD.html).
