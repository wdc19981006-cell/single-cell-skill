# Single-cell QC

Work from the `single-cell-skill` repository root. Prefer `D:/Desktop/codex-result/single-cell-skill/<DATASET>/01_download/seurat_raw.rds`; legacy `data/<GSE>/seurat_raw.rds` stays readable in place. This workflow starts independently, including days after the Loader finished. If missing, stop with “未找到 seurat_raw.rds，请先完成数据下载和原始对象构建。” Do not restart GEO Stage A, redownload raw expression, or rebuild the raw RDS unless separately requested. Fixed R scripts in `qc/` perform calculations; the Skill invokes them, reads reports and handles decisions.

All formal R calculations use the project R45 Runtime in `runtime/r45/`; its `config.py` is the sole environment definition. Output root comes from `runtime/output_config.json`; override the collection root with `--output-root`. Code paths are independent. Safe non-GEO dataset names are accepted. Historical repository results/data stay in place: read with --input, or explicitly resume the old layout with --root OLD_WORKSPACE. Use `qc/run_workflow.py` to run health checks, precheck, QC, and checkpoint recovery through `runtime/r45/run_r45.py`. Inspect `.runtime/r45/health.json` for the actual R version, `.libPaths()` and package versions. Missing R or packages stop the applicable stage; never switch R, install packages, or change machine settings. Temporary R diagnostics and all R tests also use this runtime, with `--expr` for expressions. The old shell launcher is a deprecated compatibility entrypoint.

1. Run `C:/Python312/python.exe qc/run_workflow.py <GSE> --root <repository-root> --precheck` and read `D:/Desktop/codex-result/single-cell-skill/<DATASET>/02_QC/qc_report.csv`. This checks runtime health with the QC dependencies before `qc_precheck.R`. Precheck may create the QC directory and report, but never filters the input object.
2. If `RUN/status` is `NEEDS_USER_DECISION`, stop. Report each flagged sample with group and cell count, plus any threshold or species conflict. For any `predicted_removed_fraction > 0.15` row, including the `ALL` summary row, report the predicted fraction and ask: “默认 QC 参数预计删除超过15%的细胞。是否继续使用当前QC阈值，还是修改参数？” Never remove a sample, change a threshold, group, expected doublet rate, or cell-cycle regression on your own.
3. After an explicit user answer, write `D:/Desktop/codex-result/single-cell-skill/<DATASET>/02_QC/qc_decision.json` with `decision_type`, `affected_samples`, `confirmed_by: "user"`, their literal `user_statement`, and `removed_samples`, `kept_low_cell_samples`, or `parameter_overrides` as needed. Use decision types `remove_low_cell_samples`, `keep_without_doubletfinder`, or `override_parameters` for the three low-cell choices. `accept_default_conflicts: true` records an explicit choice to retain conflicting defaults. If the user explicitly says “继续使用当前阈值”, “按当前参数继续”, or equivalent in response to predicted removal above 15%, record `decision_type: ["accept_qc_removal"]` and `accept_qc_removal: true`. For example: `{"decision_type":["accept_qc_removal"],"affected_samples":["GSM123"],"user_statement":"用户原话","confirmed_by":"user","accept_qc_removal":true}`. The `ALL` report row is a summary, not a sample ID: when only specific samples trigger, list those sample IDs; when `ALL` triggers, list every active sample ID, which also covers any individual triggers. This matches `qc_decision()` in `qc/qc_utils.R`, which requires `affected_samples` to contain real sample IDs. Never write this acceptance from the request to run QC, from a simulated answer, or without the user's explicit choice after seeing the precheck. R validates decisions against the raw object. Rerun precheck and read the new report before continuing; never re-ask for the same persisted choice.
4. When precheck is `PASS`, run `C:/Python312/python.exe qc/run_workflow.py <GSE> --root <repository-root>`. Validate the three step checkpoints and their actual figures/tables below; step-local state records input hashes, parameters and true exit codes. Existing results are validated before reuse. On failure, retain completed predecessors and resume only the failed step. An existing legacy QC final is validated without rebuilding; it does not imply QC-3 completion.

The pipeline has three resumable steps (`--step qc1|qc2|qc3|all`); a new default QC includes all three. Outputs are `D:/Desktop/codex-result/single-cell-skill/<DATASET>/02_QC/01_basic_QC`, `02_doublet_cellcycle`, and `03_ambient_RNA`. Save each RDS, plot, table, configuration and log within its step. Legacy `data/<GSE>/qc/seurat_qc.rds` is a historical QC-2 artifact, not proof that DecontX ran; validate it read-only before reuse. Never overwrite source or checkpoint RDS.

QC-1 keeps strict project defaults nFeature >200 and <4000, nCount >500 and <30000, pMT <25, pRP <100, pHB <1; these are not universal biological standards. After cell filtering keep genes expressed in more than three retained cells. Preserve pre-filter values separately, and recompute current nCount_RNA/nFeature_RNA from the retained counts. Save `seurat_QC-1.rds`, complete cell records, sample/gene summaries, before/after plots and qc_filter_reasons.csv/pdf. Rule hits overlap; *_only counts are exclusive; total_removed_cells is deduplicated. Never retune thresholds or remove a sample automatically.

QC-2 preserves verified DoubletFinder/PCA logic, runs per evidenced capture library, records pANN, DF and DF_adj, and filters only after homotypic adjustment using DF_adj. Ambiguous biological-sample/capture-library mappings require review. Score cell cycle without deleting cells by phase. Save `seurat_QC-2.rds`, all doublet/cycle plots and summaries.

QC-3 uses integer sparse RNA counts with celda DecontX, keeps original RNA unchanged and saves corrected expression in a separate assay. Save `seurat_QC-3.rds`, cell contamination estimates, sample summaries and comparison/distribution plots. Never substitute normalized data for raw counts or automatically delete cells using 2.5%, 3% or 5% contamination cutoffs. Missing requirements stop QC-3 while retaining QC-2. Formal analysis defaults to decontX. Record source metrics; retain fractional corrected values and RNA metadata. Read contamination_warnings.csv and marker_correction_review.pdf; thresholds in qc/default_config.yaml ambient are diagnostics only. Optional genuine empty-droplet background requires a complete library manifest (library_id,path,evidence) and aligned integer RDS matrices; never fabricate background. For existing QC-3 diagnosis use qc/review_ambient.py DATASET --input ABSOLUTE_RDS; it writes a new reviews/ID directory without rerunning correction.

After QC report checkpoints and limitations, then ask before separate formal analysis unless already authorized. Use [single-cell-analysis](../single-cell-analysis/SKILL.md) for fresh PCA, design-aware Harmony and user-reviewed clustering.

If a user explicitly keeps a low-cell sample without DoubletFinder, record `DF = "NotEvaluated"`, `DF_adj = "NotEvaluated"`, and `doublet_status = "SKIPPED_LOW_CELL"`; never mislabel it as a predicted singlet. The final run status must be `QC_COMPLETE_WITH_UNEVALUATED_DOUBLETS`, and the report must list the unevaluated samples and cell counts.

The historical `qc/references/01_Seurat_1.R` is reference material only. Never execute it as the production pipeline. A synthetic/mock test verifies control flow; only a test that invokes the installed DoubletFinder functions verifies real doublet computation.

All formal QC figures are generated and saved through `qc/plot_utils.R`; use its `save_sc_plot()` and shared UMAP theme/coordinate helpers for later single-cell plots. Do not scatter separate `ggsave()` size decisions through analysis scripts. The Loader's `STATUS: COMPLETE_RAW` means only the raw object exists and never grants permission to start QC.

PCA selection remains reference-compatible: `stdev/sum(stdev)` shares, strict cumulative >90% and individual <5%, and the last elbow drop >0.1. Squared-standard-deviation variance explained is diagnostic only. Read the per-sample and merged `PCA` report rows; report `PCA_LOW_DIM_WARNING` (2-3 selected with at least 10 available) without forcing extra PCs. Keep dynamic bounds and pMT-only regression. The post-filter `singlet_dimplot` uses the exact retained-cell subset of the pre-filter UMAP, including approved `NotEvaluated` cells; it never fits a second embedding.

Routine mode: read *_result.json first and invoke fixed scripts; open full logs only for concrete errors. Targeted mode: use the applicable saved-object diagnostic. Development mode: change code only for an explicit request/error and run affected tests. Persist actual decisions and avoid repeated whole-repository review or archive uploads.
